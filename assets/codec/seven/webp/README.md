# Seven Codec display portraits

Compact 512×640 WebP copies for the fixed Codec portrait panel. The original PNG masters are stored separately in the portrait pack. These are still portraits, not mouth frames or roaming sprites. Choose one from expression, time, and routine state; render dialogue and labels as native UI text.

For the SwiftUI app, validate WebP decoding on the deployment target before wiring these assets into the view. If the target lacks WebP support, use ImageIO or convert to optimized PNG.
